# Student Profile Guide

Your profile is the one place the platform learns about you. Dashboard, Semester Command Center, course recommendations,
AI Tutor, Career, Resume and Jobs all read it, so a change here shows up everywhere.

- View: menu > Profile > **Student Profile** (`/profile`).
- Edit: **Student Profile > Edit** (`/profile/edit`): identity, academic, skills, projects and experience, career goals,
  learning preferences.
- Completion: the percentage counts only details you have entered. Optional details never count against you.

Examples:
- Change your semester: the Dashboard, Semester Command Center, recommended subjects and AI Tutor context update. Your
  old notes and results stay as they were.
- Add a skill: Career role matches and new resumes include it. It is shown as "student declared, not assessed" until you
  prove it with an assessment.

Privacy: menu > Settings > **Privacy & Data** lets you set profile visibility (Strictly Private / Public), turn usage
analytics on or off (off by default) and download your data. Your email, phone and CGPA are never shown in community posts.

Troubleshooting: if a page still shows old details, refresh it. If it still shows them, report it in Pilot Feedback.
