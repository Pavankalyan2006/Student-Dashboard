# Feedback Guide

The pilot feedback page (`/pilot-feedback`) has been retired from the student app. Old links to it now open the
dashboard.

- Feedback you already sent is kept, still private to you, and still shown to the owner only under a random code.
- The page that let you withdraw an entry is gone. To have an earlier entry removed, ask the platform owner; the
  backend endpoint that deletes your own entries (`DELETE /api/v1/pilot-feedback/mine/:id`) still works.
- To report a problem or a privacy concern now, contact the platform owner directly.
