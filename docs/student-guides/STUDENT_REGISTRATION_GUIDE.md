# Registration Guide

Registration has 7 steps. Fields marked * are required; everything else is optional. Your progress is saved on the
server after each step, so you can close the page and continue later from the same step.

| Step | What you enter | Required |
|---|---|---|
| 1. Account and identity | Full name, email, password (8+ characters with a letter and a number), confirm password, agree to the Terms and the Privacy notice. Phone is optional | Yes |
| 2. Academic profile | College*, degree*, branch*, current semester*, year of study*, expected graduation year*. Optional: university, department, specialization, admission year, status, CGPA (only if you want to share it), current subjects, previous qualifications, achievements | Yes |
| 3. Technical skills | Add a skill (for example Python), then choose your level for it. A level is required for each skill you add | Can skip |
| 4. Projects and experience | Projects, technologies, GitHub/demo links, internships, certifications | Can skip ("Skip for now") |
| 5. Career profile | At least one target role or direction (for example Backend Developer, higher studies, GATE) | Yes |
| 6. Learning preferences | Preferred language*; optional explanation style, difficulty, weekly study hours, study days | Yes |
| 7. Review and complete | Check everything, then finish | Yes |

Tips:
- Semester and year must match (semester 5 is year 3).
- Type a subject or skill and press Enter (or the + button) to add it.
- Pressing the create button twice is safe: only one account is created.
- After finishing, the Dashboard may say "Optional details you can still add". That is optional, not an error.

## Troubleshooting

| Message | Meaning |
|---|---|
| "An account with this email address already exists" | Sign in instead |
| "must contain a letter and a number" | Choose a stronger password |
| A level "must be chosen" on skills | Pick Beginner / Intermediate / Advanced / Expert for each skill |
| You closed the page mid-way | Sign in again: you return to the step you were on |
