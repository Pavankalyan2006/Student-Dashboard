# Coding Lab Guide

- Open menu > Practice Labs > **Coding Lab** (`/coding`).
- Choose a language. Python 3, JavaScript, C, C++ and Java are supported when the server has the compiler; the
  language list shows what is available.
- Write code, add input if your program reads it, then **Run**. Output, errors and run time appear below.
- **Save** keeps the program in your saved list (`/coding/saved`). Saved code is private to you.
- Programs run in a sandbox with time and output limits, separate from other students.

Other labs: **SQL Lab** (`/sql-lab`) gives you your own practice database. **AI/ML Lab** (`/ml-lab`) lets you upload a
CSV, train a model and read its metrics; for the pilot use `sample-data/study-hours-synthetic.csv`. **DSA Lab** (`/dsa`).

Troubleshooting:

| You see | Do this |
|---|---|
| Time limit exceeded | Check for an infinite loop or a slow algorithm |
| Compile error | Read the first error line; it shows the line number |
| Language unavailable | Pick another language and report it in Pilot Feedback |
