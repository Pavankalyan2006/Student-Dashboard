# Courses and Learning Guide

- **Courses** (`/courses`): "Your subject" recommendations come from the current subjects in your profile. Open a course,
  then choose Enroll to follow it.
- **Notes** (`/notes`): write your own notes. AI-generated notes need AI to be switched on.
- **Documents** (`/documents`): upload your study files (only material you are allowed to share). They are private to you.
- **Flashcards** (`/flashcards`): create a deck, add cards, and review them. Rating each card schedules the next review.
- **Study Planner** (`/study-planner`) and **Learning Goals** (`/goals`): create a goal with steps. Ticking steps updates
  progress.
- **Semester Command Center** (`/semester-command-center`): your semester, subjects, exams and plans.

Troubleshooting: an empty list means you have not added anything yet; nothing is pre-filled for you. If a save fails,
your entry stays on screen. Try again, and report it if it keeps failing.
