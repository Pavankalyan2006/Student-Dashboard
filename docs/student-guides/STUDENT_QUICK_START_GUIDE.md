# Quick Start Guide (pilot)

Welcome to the B.Tech Learning Platform pilot. This is a test version: some things may not work yet, and your feedback
helps fix them. You only need to try the parts that interest you.

## 1. Get started (about 5 minutes)

1. Open the pilot address the project owner sent you.
2. Choose **Register** and complete the 7 steps (see STUDENT_REGISTRATION_GUIDE.md). You can stop and come back later.
3. You land on the **Dashboard**. Your college, branch, semester and goals are shown at the top.

## 2. Find your way around

The menu on the left (the ☰ button on a phone) has these groups:

| Group | What is in it |
|---|---|
| Learning | Dashboard, Semester Command Center, AI Tutor, Courses, Notes, Documents, Doubt Solver, Flashcards, Study Planner, Language Learning |
| Practice Labs | Coding Lab, DSA Lab, SQL Lab, AI/ML Lab, System Design Lab, Git Lab, Lab Assistant |
| Assessment | Quiz, Exam Preparation, Mock Interviews, GATE Exam Preparation |
| Project & Research | Projects, GitHub, Research, Knowledge Base |
| Career & External Platforms | Career, Resume, Mock Interviews, Internships / Applications, Placement Preparation, Connected Platforms, External Profiles, Jobs Discovery |
| Community | Community Hub, Q&A Forum, Discussions, Shared Resources |
| Profile | Unified Progress, Learning Goals, Student Profile, Notifications, Settings, **Pilot Feedback** |

## 3. What may not work during the pilot

- **AI features** (AI Tutor answers, AI flashcards, AI quizzes, interview feedback) work only if the owner has switched AI
  on for the pilot server. If not, you will see "AI unavailable". That is expected, not your mistake.
- **Jobs Discovery** shows only real listings from live job feeds. If none can be reached, the list is empty. The platform
  never makes up jobs.
- **Paper search** may only show a small curated list (marked CURATED) when live search is unreachable.

## 4. Tell us what you think

Open **Pilot Feedback** (Profile group in the menu). It is private and optional, and you can withdraw it.
See STUDENT_FEEDBACK_GUIDE.md.

## Troubleshooting

| Problem | Try this |
|---|---|
| Blank or broken page | Refresh. If it stays broken, report it in Pilot Feedback > Problem report |
| "Too many attempts" when signing in | Wait 15 minutes. This appears after repeated wrong passwords |
| Forgot password | Use "Forgot password?" on the sign-in page. If it says reset needs Firebase, contact the pilot owner |
| Something looks like another student's data | Stop and report it straight away: Pilot Feedback > Privacy or security concern |
