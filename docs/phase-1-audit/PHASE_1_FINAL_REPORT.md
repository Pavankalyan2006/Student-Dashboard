# Phase 1 Final Report: Learning Workspace (12 pages)

Date: 2026-11-05. Branch: `claude/project-thread-g85yyh`. PR: #3.

All testing used synthetic students on local servers. Nothing was deployed, and no real student data was touched.

## A. Repository overview

**Frontend**
- React 19, Vite and Tailwind.
- A custom pathname router (`src/App.tsx`) renders each page inside `AppShell`.
- The client is `src/api/client.ts`.

**Backend**
- Express runs under tsx with routers at `/api/v1`.
- Auth uses a JWT checked by `requireAuth`; the student id always comes from the token.

**Data**
- Data is held in in-memory Maps, persisted to a JSON snapshot (`server/db/persistence.ts`, registered in `server.ts`).
- Postgres is not used.

**AI**
- Gemini runs through `server/ai/provider.ts` and `AIService`. No key is configured in this environment.
